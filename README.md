# Asa Studio — Vietnamese Heritage, in Contemporary Light

Crafted and designed by **stoopiducky**.

## 💡 About

Asa Studio is reimagining lighting from the ground up. Best known for the **NOLA Lamp** collection — personalized, 3D-printed, and handcrafted in Vietnam.

---

## 🚀 Running Locally

Launch the local server:

```bash
npm start
# or
node server.js
```

Open your browser at **[http://localhost:3000](http://localhost:3000)**.

---

## 📁 Key Features & Structure

- **Hero & Story**: "Vietnamese heritage, in contemporary light"
- **Product Spotlight**: NOLA Lamp (8 colors, 6 signature charms)
- **Personalization**: "One lamp. A story that's yours alone."
- **Originality**: 3-column gallery with custom finishes & portability
- **Spaces Gallery**: 10 curated atmospheric spaces
- **Collaborations**: adidas Project, ASA Customers, Fabo × VinFast, Viral Town, Cinéus
- **Welcome Modal**: "Follow the journey" with Instagram access
- **Full Responsive Architecture**: Clean vanilla HTML5, CSS3, and modern JavaScript
